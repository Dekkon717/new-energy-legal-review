# v0.1.0 · 首个 Windows 公开版本

这是新能源合同审查助手的第一个可直接下载版本。它把现有网页工作台装进 Windows 桌面外壳，合同解析和规则匹配仍然在本地完成。

## 这版包含

- PDF、DOCX、TXT、Markdown 合同本地读取；
- 储能采购、EPC、供应链、光伏、锂电池、项目开发、电力交易和运营安全等场景规则；
- 风险分级、条款定位、证据状态、修改建议和法源核验入口；
- 相似案例、整改状态和 CSV、Markdown、JSON 导出；
- Windows 安装版与无需安装的便携版。

## 下载选择

- `新能源合同审查助手-0.1.0-x64.exe`：常规安装版，可创建快捷方式；
- `新能源合同审查助手-0.1.0-便携版.exe`：不写入安装目录，适合先体验。

安装包暂未进行商业代码签名，Windows 可能显示 SmartScreen 提示。合同审查结果用于辅助定位和复核，不构成法律意见；扫描件仍需先完成 OCR。
